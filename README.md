# 🌴 Far Away – Travel Packing List

A simple and interactive React application that helps travelers organize and manage their packing list before a trip. Users can add items, mark them as packed, sort the list, and clear everything when they're ready for a new adventure.

## ✨ Features

- ➕ Add items to your packing list
- 🔢 Specify the quantity of each item
- ✅ Mark items as packed or unpacked
- 🗑️ Remove individual items
- 📋 Sort items by:
  - Input order
  - Description
  - Packed status
- 🧹 Clear the entire packing list
- 📊 View packing progress

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/shem4soul/react-travel-list.git
```

Navigate into the project directory

```bash
cd react-travel-list
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm start
```

Open your browser and visit:

```
http://localhost:3000
```

---

## 📦 Build for Production

```bash
npm run build
```

This creates an optimized production build in the **build** folder.
